# 러시아워 바 (Rush Hour Bar)

고등학교 1~2학년 바리스타 수업용 **카페 운영 타이밍 액션 게임**입니다. 밀려드는 주문을 처리하면서 에스프레소 추출·우유 스티밍·메뉴 레시피·위생 관리를 손에 익힙니다.
학습 개념은 퀴즈가 아니라 **조작(메카닉)** 으로 들어 있습니다. 샷은 목표선에서 직접 멈추고, 분쇄도 다이얼로 추출 시간을 맞추고, 공기 주입 시간으로 거품 두께를 정하고, 담는 순서가 판정됩니다.

- 스테이지 7개, 연습 모드(타이머 없음), 튜토리얼(선배 바리스타와 첫 두 잔 따라 하기)
- 결과 화면: 별·점수, **실수 노트**(가장 많이 한 실수 3개 + 원리 + 고치는 법), **실습 체크리스트**
- 교사용 기록: 모둠별 실수 통계, CSV 내보내기, 전체 스테이지 해금
- 서버·로그인·DB 없음. 기록은 이 기기의 브라우저(localStorage)에만 저장합니다.

기획 기준 문서: [GAME_PLAN.md](GAME_PLAN.md) · 세계관·연출: [THEME.md](THEME.md)

## 1. 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 `http://localhost:5173`)를 엽니다.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사(`tsc --noEmit`) 후 `dist/`에 정적 파일 생성 |
| `npm run preview` | 빌드 결과 미리 보기 |
| `npm test` | 단위 테스트 + 정답 입력 봇 시뮬레이션(Vitest) |
| `BALANCE=1 npx vitest run tests/balance.test.ts` | 밸런스 리포트(봇 반응 속도별 스테이지 클리어율) |

### 조작
- 터치·마우스: 탭, 누르고 있기(공기 주입·롤링·물/우유 붓기), 서빙대 컵을 손님에게 드래그(또는 컵 탭 → 손님 탭)
- 키보드: `1`~`4` 작업대 전환, `Space` 추출 시작/정지, `A` 공기 주입, `S` 롤링(누르는 동안), `Enter` 서빙, `Esc` 일시정지
- 화면: 태블릿 가로(주 사용) · 전자칠판(자동 확대) · 휴대폰 세로(작업대를 아래 탭으로 전환)

## 2. 배포 (Vercel)

1. 이 저장소를 GitHub에 올리고 [vercel.com](https://vercel.com)에서 **New Project → 저장소 가져오기**를 누릅니다.
2. Framework Preset은 **Vite**, Build Command는 `npm run build`, Output Directory는 `dist`입니다(자동 감지됨).
3. **Deploy**를 누르면 끝입니다. 환경 변수와 API 키는 필요 없습니다.

다른 정적 호스팅(GitHub Pages, Netlify 등)도 `dist/` 폴더만 올리면 됩니다.

## 3. 데이터를 바꿔 재사용하는 방법

모든 콘텐츠와 기준 수치는 `src/data/`에만 있습니다. **게임 코드를 고치지 않고 데이터 파일만 바꾸면** 다른 기준이나 메뉴로 쓸 수 있습니다. 바꾼 뒤 `npm test`를 실행하면 데이터 무결성 검사와 정답 입력 봇이 그대로 클리어되는지 확인할 수 있습니다.

| 파일 | 내용 | 이런 때 고치세요 |
|---|---|---|
| `standards.ts` | 샷 기준(양·시간), 분쇄도 흐름, 스티밍 온도·거품 속도, 컵 용량, 판정·점수·위생 규칙 | 교재의 추출 시간·온도 기준이 다를 때 |
| `menus.ts` | 메뉴 17개 레시피(컵, 샷 종류, 재료·양·순서, 거품 두께) | 레시피 비율·순서를 수업 기준으로 맞출 때 |
| `stages.ts` | 스테이지 7개(메뉴, 인내심, 동시 주문, 허용 오차, 가이드, 이벤트, 클리어 조건, 손님 간격) | 난이도 조정(**밸런스 수치는 이 파일에서만**) |
| `feedback.ts` | 실수 17종별 손님 대사·원리·고치는 법·실습 확인 | 설명 문구를 수업 용어로 바꿀 때 |
| `practiceChecks.ts` | 결과 화면 실습 체크리스트 | 실습실 장비·절차에 맞출 때 |
| `customers.ts` | 손님 3유형(인내심·반품 기준·팁 배율, 대사) | 대사·성격을 바꿀 때 |
| `tutorial.ts` | 선배 바리스타 튜토리얼 대사와 단계 | 안내 문구를 바꿀 때 |
| `mistakeLabels.ts` | 교사용 통계의 실수 짧은 이름 | |

메뉴를 추가할 때는 `menus.ts`에 레시피를 넣고 `stages.ts`의 `menuIds`에 id를 넣으면 됩니다. 재료 버튼은 스테이지 메뉴에 들어 있는 재료로 자동 구성됩니다.

## 5. 게임 규칙 수치 (교재 대조 대상 아님)

`standards.ts`의 `JUDGE_RULES`·`SCORE_RULES`·`HYGIENE_RULES`와 `stages.ts`에 있습니다.

- 한 잔 100점 = 구성·비율·순서 40 + 샷 30 + 우유 20 + 속도 10 (우유 없는 메뉴는 구성 50 + 샷 40 + 속도 10)
- 70점 미만 반품(꼼꼼한 미식가는 80점), 다른 메뉴로 인식되면 반품
- 콤보: 80점 이상 연속 서빙 시 팁 배율 1.0 → 1.2 → 1.5
- 위생(스테이지 6·7): 퍽 미처리 샷 품질 −20·게이지 −10, 스팀완드 미관리 우유 품질 −20·게이지 −15, 게이지 0이면 마감 청소(약 20초) 후 50%로 재개
- 별: ★ 클리어 / ★★ 평균 80점 이상 / ★★★ 평균 90점 이상 + 반품 0

## 6. 개인정보·보안

- 이름·연락처·생년월일을 받지 않습니다. 학생 구분은 모둠 번호(1~8) 또는 '개인 연습'뿐입니다.
- 기록은 이 기기의 localStorage에만 저장하며 외부로 보내지 않습니다. 분석 도구·광고 스크립트·카메라·마이크를 쓰지 않습니다.
- API 키나 비밀값이 없습니다. CSV는 브라우저 다운로드로만 내보냅니다.
- 오류가 나면 쉬운 한국어 안내만 보여 주고, 기술적인 오류 내용은 화면에 표시하지 않습니다.
- 푸터의 `[공급자명]`과 개인정보 처리방침·이용 안내 페이지는 등록 전에 채워 주세요.
